# 坦克大战 - Battle City

经典坦克大战网页游戏，使用 HTML5 Canvas 和 JavaScript 实现。

## 游戏操作

- **方向键** / **WASD** - 移动坦克
- **空格键** / **Z 键** - 射击

## 游戏规则

- 消灭所有敌军坦克即可过关
- 保护基地（金色鹰徽）不被摧毁
- 每关有 12+ 辆敌军坦克
- 击毁敌军获得分数（连击有加分）
- 共有 3 条命

## 特性

- 4 个预设关卡 + 无限随机生成关卡
- 可破坏的砖墙和不可破坏的钢墙
- 敌军 AI（追踪玩家、随机移动）
- 粒子爆炸效果
- 音效（Web Audio API）
- 最高分本地存储

## 运行

直接在浏览器中打开 `index.html` 即可运行。
